安装 Rallumi

macOS 试用版

  1. 安装并登录 Codex 桌面应用。
  2. 解压试用包，双击 Install Rallumi.command，等待终端显示“Installation complete”。本机缺少 Node.js 24 或更新版本时，安装程序会从 Node.js 官网下载运行环境。
  3. 打开 Codex，在左侧点击紫色的 Rallumi 图标。如果当时已开着 Codex 且图标未出现，退出后重新打开一次。

发一条试试

打开「Rallumi Starter Group」，发送 @Coordinator 帮我列三个产品试用步骤。群里还有研究、执行、复核。左侧底部的「使用说明」可打开帮助，「语言」可切换中英文。

聊天保存在哪里

Rallumi 在这台 Mac 上创建自己的群聊数据，并使用你登录的 Codex 处理任务。试用包里的示例群从空白开始。

安装或连接失败

先查看安装窗口里的错误，再运行一次同一个安装文件。遇到 Codex 提示需要更新或本地插件受组织限制，请按 Codex 的提示处理。
