Install Rallumi

macOS preview

  1. Install and sign in to the Codex desktop app.
  2. Unzip the download, double-click Install Rallumi.command, and wait for “Installation complete.” The installer downloads Node.js from nodejs.org if needed.
  3. Open Codex and select Rallumi in the sidebar. If the icon is missing after installation, quit and reopen Codex.

Send a test message

Open Rallumi Starter Group and try @Coordinator Help me outline a three-step product trial plan. Use Help in the left sidebar for guidance, or Language to switch between English and Simplified Chinese.

Where conversations are stored

The starter group begins with an empty chat. Rallumi stores group data on your Mac and runs tasks through your signed-in Codex account.

If installation fails

Read the error in the installer window and run the installer again after addressing it. If Codex needs an update or your organization restricts local plugins, follow the instructions in Codex.
